# Icon sources

`touch-icon-celtic.svg` is the canonical vector source for the favicon,
Apple touch icons, and web app icons. `coda-celtic.svg` is the transparent
footer variant. Both use the selected B2 design with four identical arms and
a fine gap between the cross and ring.

`icon-celtic.html` renders every PNG directly from the same vector geometry at
its final dimensions. The checked-in PNGs live in `images/`. The root
`favicon.ico` contains independent 16, 32, and 48 pixel renders of
`touch-icon-celtic.svg`; it is not produced by resizing another PNG.
